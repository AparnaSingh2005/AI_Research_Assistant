# AI Research Paper Assistant

An AI-powered application that allows users to upload research papers, ask questions, generate summaries, create quizzes, and identify research gaps using Retrieval-Augmented Generation (RAG).

## Tech Stack

- Python
- Streamlit
- LangChain
- ChromaDB
- HuggingFace
- PyMuPDF
